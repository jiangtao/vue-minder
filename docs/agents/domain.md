# Domain Docs

工程技能在探索与设计前，按以下约定读取项目领域文档。

## 读取顺序

- 优先读取仓库根目录的 `CONTEXT.md`；若存在 `CONTEXT-MAP.md`，则读取其中指向的相关上下文。
- 读取 `docs/adr/` 中与当前工作相关的 ADR。
- 文件不存在时直接继续，不预先创建；仅在 `/domain-modeling` 真正确定术语或架构决策时按需创建。

## 布局

本仓库采用单一上下文：根目录使用一个 `CONTEXT.md`，系统级 ADR 放在 `docs/adr/`。

## 使用规则

- Issue、规格、测试与实现统一使用 `CONTEXT.md` 定义的术语。
- 避免使用词汇表明确排除的同义词。
- 如输出与现有 ADR 冲突，必须明确指出，不得静默覆盖。
