# Triage 标签

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工执行 |
| `wontfix` | `wontfix` | 不在计划内 |

右侧标签名应与 GitHub 中的实际标签保持一致。
